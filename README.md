This repository contains the frontend architecture for **Refacciones Toluca**, a specialized automotive workshop and parts supplier. Engineered as a **Premium B2B Web Architecture**, this project is designed to deliver a high-impact corporate presence, maximize client trust, and provide a highly scalable foundation for digital business operations.

## ✨ Premium Features & Architecture

* **Corporate Visual Design:** A premium *dark-gold* aesthetic tailored specifically for the automotive sector, designed to project maximum trust, authority, and mechanical precision.
* **High-Impact Animations:** Integration of fluid UI transitions and optimized video backgrounds that elevate the user experience without compromising load speeds.
* **Sector-Optimized Structure:** Strategically mapped sections including an interactive Parts Catalog with dynamic filtering, specialized Service cards, real Google Reviews integration, and an embedded Location module.
* **SEO & Performance Optimized:** Powered by Vite, ensuring lightning-fast Hot Module Replacement (HMR) during development and heavily optimized, minified assets for peak production performance and SEO ranking.
* **Flexible & Scalable Foundation:** Built with a modular component approach using Tailwind CSS, preparing the B2B catalog for seamless future backend or API integrations.

## 🛠 Technologies Used

* **Build Tool:** Vite (Next-generation frontend tooling)
* **Styling:** Tailwind CSS (Utility-first CSS framework for rapid UI development)
* **Core:** Semantic HTML5, Vanilla JavaScript (ES6+)
* **Integrations:** Interactive Maps, Google Reviews UI layout, WhatsApp Business API direct routing.
